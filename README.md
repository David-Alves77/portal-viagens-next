
# 🌍 Portal de Viagens

Portal de viagens desenvolvido com Next.js, React,
TypeScript e CSS Modules.

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática
do curso Desenvolvedor Full Stack Python da EBAC.

A aplicação apresenta destinos turísticos utilizando
componentes reutilizáveis e rotas baseadas em arquivos.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- CSS Modules
- HTML5
- CSS3

## Funcionalidades

- Página inicial de apresentação
- Página de destinos turísticos
- Listagem de quatro destinos
- Componentes reutilizáveis
- Navegação com next/link
- Layout compartilhado
- Design responsivo

## Estrutura

- app/: páginas e rotas
- components/: componentes reutilizáveis
- data/: dados simulados dos destinos

## Como executar

É necessário ter Node.js instalado.

1. Clone o repositório.
2. Entre na pasta do projeto.
3. Instale as dependências:

npm install

4. Execute o projeto:

npm run dev

5. Acesse:

http://localhost:3000
